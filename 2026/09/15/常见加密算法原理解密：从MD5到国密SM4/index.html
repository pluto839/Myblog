常见加密算法原理解密：从MD5到国密SM4

前言

在 CTF 攻防、Web 安全或逆向工程中，加密算法几乎是绕不开的基础。你经常会在题目里看到 eyJ... 开头的 Base64 长串、md5 破解、RSA 共模攻击、AES 密文……如果连算法类型都识别不出来，解题更是无从谈起。

本文是对一份加密算法教学视频的系统整理，覆盖三大类共 9 个主题：

类别 算法
哈希（摘要） MD5、SHA-1、SHA-256
对称加密 DES、AES、国密 SM4
非对称加密 RSA、国密 SM2
加密体制总览 对称加密 vs 非对称加密

读完本文你将掌握：每种算法的基本原理、典型特征（用于CTF快速识别）、以及常见攻击套路。

一、加密体制总览：对称加密 vs 非对称加密

在学习具体算法前，先建立全局观。加密体制主要分两大类。

1.1 对称加密（Symmetric Encryption）

加密和解密使用同一个密钥，也叫”共享密钥”或”会话密钥”。

优点 缺点
速度快（硬件加速）、吞吐量大 密钥分发困难（双方如何安全拿到同一把钥匙？）
适合加密大量数据 n 个人两两通信需要 C(n,2) 把密钥

代表算法：DES、3DES、AES、国密 SM4、RC4、Blowfish。

1.2 非对称加密（Asymmetric Encryption）

基于公钥密码学，使用一对密钥：公钥（Public Key） 和 私钥（Private Key）。

  • 公钥加密 → 私钥解密（加密/保密）
  • 私钥签名 → 公钥验签（认证/防篡改）
优点 缺点
解决密钥分发问题（公钥公开） 速度慢（大整数/椭圆曲线运算）
支持数字签名 不适合加密大数据量

代表算法：RSA、ECC（椭圆曲线）、国密 SM2。

1.3 为什么非对称加密不直接用于数据加密？

非对称加密速度太慢，实际场景（如 HTTPS）用的是 混合加密：

  1. 公钥加密方式安全地交换一个临时对称密钥（会话密钥）
  2. 后续大量数据用 对称加密（如 AES）高效传输

私钥必须严格保密，公开公钥即可。非对称加密的安全性建立在某个数学难题上（详见 RSA / SM2 章节）。

二、哈希算法：MD5、SHA-1、SHA-256

哈希（散列/摘要）算法严格来说不是”加密”，因为它不可逆——无法从结果反推原文。它把任意长度的输入映射为固定长度的”指纹”。

哈希的核心性质：

性质 含义
单向性 由输入得输出容易，反推几乎不可能
定长输出 不管输入多长，输出固定长度
雪崩效应 输入变一个 bit，输出完全不同
抗碰撞（理想） 很难找到两个不同输入得到相同输出

2.1 MD5（Message-Digest 5）

  • 输出 128 位（16 字节，32 个十六进制字符）
  • 1991 年由 Ronald Rivest（RSA 中的 R）设计，由 MD4 改进而来
  • 以 512 位为单位分块处理，4 个 32 位初始寄存器，共 4 轮、每轮 16 步 = 64 步迭代

现状：已被攻破！ 2004 年王小云团队找到 MD5 碰撞，2008/2012 年成功构造了可实际利用的证书与格式碰撞。不要再用于密码存储或安全校验。

MD5 在 CTF 中主要是弱口令/明文映射玩法：

  • 在线破解：cmd5、somd5、md5online
  • 字典暴力：hashcat、john the ripper

2.2 SHA-1（Secure Hash Algorithm 1）

  • 输出 160 位（20 字节，40 个十六进制字符）
  • 1995 年发布，结构类似 MD5，但用了 5 个 32 位寄存器（多一个），共 4 轮、每轮 20 步 = 80 步
  • 分组仍为 512 位

现状：已被攻破！ 2017 年 Google 与 CWI 发布 SHAttered 攻击，成功构造了两个不同 PDF 拥有相同 SHA-1 值。Git 已弃用 SHA-1，TLS 证书停止签发 SHA-1。

2.3 SHA-256（SHA-2 家族）

  • 输出 256 位（32 字节，64 个十六进制字符）
  • SHA-2 家族成员还包括 SHA-224、SHA-384、SHA-512
  • 分组 512 位，使用 8 个 32 位寄存器，共 64 轮
  • 轮常量的取法：前 64 个素数立方根的小数部分前 32 位

现状：目前安全，尚无有效攻击。广泛用于 TLS 证书、Git 版本控制、比特币挖矿（SHA-256d）。

2.4 哈希算法特征速查（CTF 识别）

算法 输出长度(bit) hex 字符数 是否安全
MD5 128 32 ❌ 已碰撞
SHA-1 160 40 ❌ 已碰撞
SHA-256 256 64 ✅ 安全
SHA-512 512 128 ✅ 安全

三、对称加密：DES、AES、国密 SM4

3.1 DES（Data Encryption Standard）

  • 分组 64 位，密钥 64 位（有效密钥 56 位，8 位用于奇偶校验）
  • 采用 Feistel 结构，共 16 轮
  • 每轮流程：初始置换 IP → 16 轮 Feistel 迭代（轮函数 F 包含扩展置换E、S盒代换、P盒置换）→ 逆置换 IP⁻¹

结构特点：

  • 初始化置换 IP：将 64 位明文重新排列
  • 轮函数 F：扩展置换 E（32→48）→ 与子密钥异或 → S 盒代换（48→32）→ P 盒置换（32→32）
  • 子密钥调度：56 位密钥经 PC-1 压缩、循环左移、PC-2 压缩生成 16 个 48 位子密钥

现状：已不安全！ 56 位密钥太短，1998 年 EFF 的 Deep Crack 设备 56 小时即可暴力破解全部密钥。

3DES：用三个 56 位密钥做 加密-解密-加密（EDE），实际密钥长度至少 112 位，安全性大幅提升，但速度慢，已被 AES 取代。

3.2 AES（Advanced Encryption Standard）

  • 2001 年 NIST 标准化，算法原名 Rijndael
  • 分组 128 位，密钥长度支持 128 / 192 / 256 位（对应 AES-128/192/256）
  • 不是 Feistel 结构，而是 SPN（代换-置换网络）

轮数与密钥长度对应：

算法 密钥长度 轮数
AES-128 128 10
AES-192 192 12
AES-256 256 14

每一轮（除首轮与末轮）包含 4 个步骤：

步骤 作用
SubBytes 通过 S 盒非线性替换，提供混淆
ShiftRows 对状态矩阵行移位，扩散
MixColumns 对列做矩阵乘法混合，扩散（末轮省略）
AddRoundKey 与轮密钥异或

AES 至今无有效攻击，配合硬件指令（AES-NI）极快，是当前最主流的对称加密标准。

3.3 国密 SM4（对称加密）

这是课程中附带 PPT 的算法，信息最完整，可见其重要性。

发展历程：

时间 事件
2006 原名 SMS4，由国家密码管理局公布，为 WAPI 标准设计
2012 正式成为国密标准 GB/T 32907-2016
2021 被纳入 ISO/IEC 国际标准，获全球认可

核心参数：

参数 值
分组长度 128 位
密钥长度 128 位
迭代轮数 32 轮

结构：采用 32 轮 Feistel 结构，每轮对数据做混淆与扩散。核心是轮函数 F：

由合成置换 T 和异或构成：

  • 非线性变换 τ：本质是 S 盒，采用 8×8 字节置换表，对每个 8 位输入独立查表替换，打破明文与密文之间的线性关系
  • 线性变换 L：对 32 位字做循环移位与异或，实现扩散

S 盒是 SM4 唯一的非线性部件，采用公开且固定的置换表，保证算法一致性、可验证性。

密钥扩展：将 128 位初始密钥扩展为 32 个 32 位的轮密钥，供每轮使用。

广泛应用场景：

领域 典型应用
政务 电子公文传输与签署、政务云数据存储、涉密终端身份认证（SM4 加密芯片）
金融 金融 IC 卡（保护密钥与交易数据）、电子银行、第三方支付
通信 国密 VPN、5G 通信、物联网（智能家居 / 工业传感器轻量级加密）

SM4 vs AES：

维度 SM4 AES
设计目标 与 AES-128 相当 —
安全性 能抵御已知攻击 能抵御已知攻击
性能 嵌入式设备上简洁设计更占优 通用处理器有广泛硬件加速（AES-NI）通常更快

未来展望：挑战是国际兼容性、硬件加速支持不足、量子计算潜在威胁；机遇是国产化政策强制要求、技术创新、国际标准提升影响力。

3.4 对称算法对比

算法 分组 密钥 轮数 结构 状态
DES 64 56 16 Feistel ❌ 不安全
3DES 64 112+ 16×3 Feistel ⚠️ 过渡
AES 128 128/192/256 10/12/14 SPN ✅ 主流
SM4 128 128 32 Feistel ✅ 国密

四、非对称加密：RSA、国密 SM2

4.1 RSA

1977 年美国三位科学家 Rivest、Shamir、Adleman 提出，是第一个实用的公钥密码算法。

数学基础：大整数分解难题（IFP）——两个大素数相乘很容易，但由乘积分解回两个素数极难。

密钥生成流程：

  1. 选两个大素数 p、q
  2. 计算 n = p × q（n 公开，作为公钥的一部分）
  3. 计算欧拉函数 φ(n) = (p-1)(q-1)
  4. 选择一个与 φ(n) 互质的加密指数 e（通常取 65537 = 2¹⁶+1）
  5. 计算 d = e⁻¹ mod φ(n)（d 为私钥）

n 的位长直接决定安全性，现在要求 2048 位以上。

攻击 触发条件 思路

共模攻击 两个密文同 n 不同 e 扩展欧几里得找 s、t，s·e₁+t·e₂=1
低加密指数 e=3 少组相同明文广播 中国剩余定理 + 开 e 次方
Wiener 攻击 d 过小 连分数逼近

4.2 国密 SM2（非对称加密）

SM2 是国密体系中的椭圆曲线公钥密码算法（ECC），基于 256 位素域曲线（SM2P256V1）。

数学基础：椭圆曲线离散对数问题（ECDLP）。已知基点 G 和点 k·G，求 k 极难。

主要功能：

功能 说明
数字签名 电子签章、法律效力
密钥交换 双方协商会话密钥
公钥加密 数据保密传输

SM2 vs RSA（同安全强度下）：

维度 SM2（ECC） RSA
密钥长度 256 位 2048/3072 位
存储/带宽 占用小 占用大
运算速度 快 较慢

椭圆曲线用更短的密钥达到与 RSA 相当甚至更高的安全性，是国密体系核心，配合 SM3（哈希）、SM4（对称）构成完整国密算法族。

五、CTF 密码题实战：识别与解题速查

5.1 如何根据”密文特征”识别算法

拿到题目先看密文形态：

密文特征 可能是
eyJ... 或 = 结尾的 A-Za-z0-9+/ Base64（通常是载体，还需结合长度判断）
64 hex 字符 / 32 字节 SHA-256 或 AES-256
32 hex 字符 / 16 字节 MD5 或 AES-128
16 字节的乱码或 hex，且带 IV AES 分组加密
一长串与原文等长的字符 对称加密或异或/流密码
可逆字符替换 古典密码（凯撒/栅栏等）

5.2 常用工具链

工具 用途
hashcat / john Hash 暴力破解（MD5/SHA）
CyberChef 万能编码/解码、魔改配方
RsaCtfTool RSA 一键多种攻击
factorDB 在线分解 n
yafu / SageMath 本地分解大整数 / 数学运算

RSA 优先：很多 RSA 题的 n 直接能在 factordb.com 分解，先把 n 丢进去看一眼，往往直接出题。

写在最后

密码学是整个安全领域的基石：

  • 对称加密（AES/SM4）：快，保护数据的”状态”安全
  • 非对称加密（RSA/SM2）：慢，解决密钥分发并支持签名
  • 哈希（SHA-256）：不可逆，完整性校验与口令存储

学习时的建议：

  1. 先能识别算法，再谈破解——CTF 里 80% 的题卡在识别上
  2. 对称加密重点关注 密钥长度与分组模式（ECB/CBC）
  3. 哈希题别硬破，优先查表（cmd5 等）
  4. RSA 记住前面那 6 种攻击，做几道题就熟了
  5. 国密（SM2/SM3/SM4）在国内未来只会越来越多，提早了解不吃亏

会识、会算、会借工具，密码题手到擒来。
