CTF逆向刷题入门指南：IDA从安装到动态调试

前言

逆向工程（Reverse）是 CTF 的四大方向之一，核心是拿到一个编译好的程序，不看源码也要搞清楚它干了什么，最终还原出 flag。如果你想学逆向，起点就是 IDA，然后把字符串、伪代码、动态调试、脱壳、常见加密这些基本功逐个打通。

这篇笔记记录了我确定逆向方向后连续刷题的真实过程，覆盖了：

类别 题目
静态分析入门 Begin、逆向工程入门指北
动态调试 Speed、Plzdebugme
壳与脱壳 Upx
常见加密 X0r、A cup of tea（TEA）、尤皮·埃克斯（自写加密）
多段 flag 拼接 Puzzle

一、确定方向：为什么选逆向 + 装 IDA

学了几天 Web 后，我把方向确定为 逆向工程，第一步就是下载 IDA（Interactive Disassembler，交互式反汇编器），它是逆向最主流的工具，Windows/Linux 程序、Android APK 都能反编译。

IDA 三个最常用的快捷键（贯穿整个刷题过程）：

快捷键 作用
Shift+F12 打开字符串窗口，看程序里的明文字符串（最常见的切入点）
F5 把汇编伪代码化，变成接近 C 的代码，最常用
F2 / F9 下断点 / 开始调试（动态调试用）

三、动态调试

3.1 Speed：断点 + 动态调试绕过 sleep

题目描述：”你看到我的小马了吗？她跑得很快……” 下载 speed.zip 解压出 speed.exe，用 IDA 打开。

但直接静态分析没有思路，改用动态调试：

  1. Shift+F3 打开 Functions（函数列表） 窗口
  2. 按字母找 WinMain（W 开头），双击跳到反汇编视图
  3. 按 F5 看伪代码

发现程序 sleep 时间太短（或利用 sleep 卡了流程），给它添加断点（F2），按 F9 运行，顺利拿到 flag。

经验：遇到”运行很快”、”看不到过程”的题，答案往往就藏在动态调试里——下断点让它停下来。

四、壳与脱壳

4.1 Upx：识别 UPX 壳并脱壳

先回答三个问题——壳是什么？UPX 是什么？UPX 用来干什么？

  • 壳（packer）：给程序加一层”外套”，运行时解压真正的代码，用来防逆向、压缩体积
  • UPX：最经典的免费压缩壳软件
  • 用途：让静态分析时看不到真实的逻辑，必须先脱壳

写在最后

从装好 IDA 到流畅刷题，本质是掌握三件事：看字符串、看伪代码、会脱壳会调试。这三步能解决逆向 80% 的入门题。

给逆向新手的学习路径建议：

  1. 先练 Shift+F12 + F5，把签到题、字符串拼接题刷熟
  2. 再看动态调试（F2/F9），应对”跑得太快”的题
  3. 然后学脱壳（UPX 起步），理解”壳”的概念
  4. 最后积累常见加密（异或、TEA、Base64 变体）的识别与解密脚本

会看字符串，会按 F5，会写解密脚本——逆向入门就是这么简单。
