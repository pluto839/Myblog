Web渗透测试信息收集完全指南：从入门到实战

前言：信息收集的意义

在渗透测试（打点）中，信息收集是整个攻击链的起点。你收集的广度决定了你能找到多少攻击面。信息收集不到位，后续的漏洞利用、权限提升都无从谈起。

本文将信息收集拆分为以下几个阶段：

阶段 内容
组织信息收集 WHOIS、ICP备案、企业信息、SEO权重
Web资产探测 技术栈识别、旁站与C段、端口扫描
子域名收集 证书透明度、OneForAll、在线工具
指纹与目录 框架识别、目录爆破、敏感文件扫描
CDN绕过 历史解析、邮件IP、漏洞利用
信息泄露 GitHub泄露、JS信息、Google Hacking
自动化收集 ARL灯塔等工具整合

一、组织信息收集

1.1 WHOIS 查询

WHOIS查询是信息收集的第一步，可以获取域名的注册者邮箱、姓名、电话、地址、IP等信息。中小型网站的域名注册者往往是网站管理员，这些信息对社工攻击至关重要。

在线工具：

平台 地址
站长之家 https://whois.chinaz.com/
全球WHOIS https://www.whois.com/whois/

命令行工具：

Kali Linux 自带 whois 命令，直接查询：

获得邮箱后，利用搜索引擎反查该邮箱，挖掘更多个人信息。

1.2 ICP 备案查询

域名备案信息中可以查到主办单位名称、网站名称、首页、经营范围，以及该单位备案的其他网站——这意味着你可能通过一个站点发现目标的全部站点。

平台 地址
ICP备案查询网 https://www.beianx.cn/
站长之家ICP查询 https://icp.chinaz.com/

1.3 企业信息收集

通过企业信息查询平台，可以挖掘出公司的子公司、关联网站、法人代表等信息。

平台 地址
天眼查 https://www.tianyancha.com/
爱企查 https://aiqicha.baidu.com/
小蓝本 https://www.xiaolanben.com/

小蓝本在信息收集中尤其好用，可以快速找到企业关联的多域名和资产信息。

1.4 SEO 权重查询

SEO权重用于评估网站在搜索引擎中的排名和权重，同时可以发现该域名下的其他站点。

平台 地址
站长之家 https://rank.chinaz.com/all/
爱站 https://www.aizhan.com/cha/

二、Web 资产信息收集

2.1 Web 基本架构识别

在渗透目标时，首先需要了解目标的技术栈：

维度 常见技术
开发语言 ASP、PHP、ASPX、JSP、Java
程序源码 自研系统、开源系统、框架开发
中间件容器 IIS、Apache、Nginx、Tomcat、WebLogic、JBoss、GlassFish
数据库 Access、MySQL、MSSQL、Oracle、DB2、Sybase、Redis、MongoDB
框架信息 ThinkPHP、Spring、Shiro、Struts2
第三方软件 phpMyAdmin、vs-ftpd、FCKeditor、KKFileView

2.2 技术栈识别方法

  1. 通过Header头部来判断 — 查看响应的 Server、X-Powered-By 等字段
  2. 通过 Wappalyzer 插件来判断 — 浏览器自动识别技术栈
  3. 通过在线工具识别 — http://whatweb.bugscaner.com/look/

2.3 旁站与 C 段信息

旁站往往是业务功能站点，攻击难度可能低于主站。建议的收集流程：

先收集已有 IP 的旁站 → 再探测 C 段 → 确认 C 段目标 → 再在 C 段基础上收集旁站

功能 平台
旁站在线查询 https://chapangzhan.com/
C段在线查询 https://fofa.info/

2.4 端口信息收集

当给定的Web服务攻击难度较大时，可以对目标服务器的其他端口进行探测，寻找脆弱服务。若获取到脆弱的服务（如未授权的Redis、RDP等），往往能直接获取服务器权限。

端口号范围：0 - 65535

六、CDN 绕过

6.1 CDN 简介

CDN（Content Delivery Network，内容分发网络）通过在全球部署节点服务器，将用户请求重定向到最近的节点，加速访问。但这也意味着我们拿到的IP是CDN节点的IP，而非真实服务器IP。

绕过CDN的核心目标是获取真实IP。

6.2 历史解析记录

查找域名的历史DNS解析记录，可能找到未配置CDN之前的真实IP。

方法 工具
IP138历史解析 https://site.ip138.com/
接口查询 https://get-site-ip.com/

6.3 子域名绕过

很多CDN只对主域名进行了加速，子域名可能直接解析到真实IP。结合上面的子域名收集方法即可发现。

6.4 国外 IP 访问

部分CDN在国内加速但国外直接回源。从国外发起请求可能获取真实IP。

在线全球Ping：https://tools.ipip.net/ping.php

6.5 邮件 IP 获取

邮件服务器向外部发送邮件时，邮件头部源码中会包含服务器的真实IP。

触发方式：邮箱注册、激活、找回密码等

6.6 APP 与邮件服务器域名

原理相同，通过全球Ping域名查找真实IP：

  • APP需要抓包获取真实域名
  • 邮件服务器域名通常前缀为 smtp、pop

6.7 利用漏洞获取 IP

利用漏洞让目标服务器主动出网，获取的来源IP即为真实IP。

常见利用点：

  • .zip、.rar 等网站备份文件
  • phpinfo 信息泄露

9.1 JS 文件信息收集

网站的JS文件中可能包含大量敏感信息：身份证号、手机号、邮箱、Access Key/Secret Key、账号密码、各种API接口。

手工搜索关键字：api、get、post、url、path、key
