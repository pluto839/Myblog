从零搭建极客博客：用 Hexo 打造个人技术笔记站

前言：为什么要建个人博客？

在这个信息爆炸的时代，我始终相信：最好的学习方式是教别人，而最好的教别人方式是写下来。

在浏览了大量技术博客（比如 itsa1right.ink、blog.yanxisishi.top）之后，我决定搭建一个属于自己的极客笔记站。经过调研，我选择了以下技术栈：

组件 选择 理由
框架 Hexo 快速、简洁、Node.js 生态
主题 Icarus 卡片风格、响应式、高度可定制
评论 Giscus 基于 GitHub Discussions，无需后端
部署 GitHub Pages 免费、稳定、与 Git 工作流无缝集成

环境准备

必要软件

  • Node.js：https://nodejs.org（下载 LTS 版本）
  • Git：https://git-scm.com

第一步：初始化 Hexo 项目

打开 http://localhost:4000 即可看到默认博客。

第二步：配置 Icarus 主题

Icarus 是一款简洁、响应式的卡片风格主题，非常适合技术博客。

第三步：创建 Icarus 主题配置

在博客根目录创建 _config.icarus.yml。这是最关键的一步！

第四步：配置 Giscus 评论

最初我想用 Valine（基于 LeanCloud），但发现 LeanCloud 现在对个人开发者限制很多，注册和使用都很麻烦。

经过对比，我选择了 Giscus：基于 GitHub Discussions，完全免费，无需数据库。

开启步骤

  1. 进入你的 GitHub 仓库，开启 Discussions：
    https://github.com/yourname/repo/discussions → 点击 “Set up discussions”

  2. 访问 https://giscus.app，用 GitHub 登录，选择你的仓库，按提示操作

  4. 填入 _config.icarus.yml 即可

缺点：评论者必须有 GitHub 账号

遇到 Author identity unknown？

进入仓库 Settings → Pages → Source 选择 Deploy from a branch → Branch 选 main → Save

日常写作流程

以后每次写文章只需要三步：

踩坑记录

问题 原因 解决方案
Connection was reset 国内网络无法访问 GitHub 配置 Clash 代理到 Git
Author identity unknown Git 全局身份未配置 git config --global user.name/email
RepoId not found 配置文件用了 repo_id 而非 repoId 改用驼峰命名 repoId
首页 404 所有文章删除后 Hexo 不生成 index 至少保留一篇文章或创建静态 HTML
友链页 404 Icarus 没有 layout: links 改用 layout: page

写在最后

如果你也想搭建自己的技术博客，希望这篇文章能帮你少走一些弯路。
